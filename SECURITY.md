# Security policy

This repository currently contains a static UI showcase. Audio, location, analysis and account interactions use local demonstration state. It does not collect recordings, coordinates, credentials or agricultural data, and it has no backend or real AI integration.

Report a suspected vulnerability privately to the repository maintainer. If GitHub private vulnerability reporting is enabled, use **Security → Report a vulnerability**. Do not publish credentials, personal information or exploit details in a public issue. Include the affected commit, reproduction steps and impact; use synthetic data.

Only the current default branch is maintained. Dependency update proposals and CI checks support review; they do not establish that the application is free of vulnerabilities.

See [the security baseline](docs/security.md) for enforced boundaries, hosting requirements and work required before real features can be added.
